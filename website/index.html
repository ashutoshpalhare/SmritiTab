Designed to stay yours

A useful workspace.
Not another data silo.

SmritiTab is built as a local-first browser extension. Your dashboard should feel personal without requiring an account or a SmritiTab cloud service.

Local-first storageExtension data is stored in your browser using Chrome's local storage.
No app backend or analyticsSmritiTab does not include its own account server, telemetry or analytics service.
Clear external servicesWeather uses Open-Meteo. Optional remote wallpapers load only when you choose them.
⌑

Your browser is the home base.

SmritiTab does not sync your dashboard through a SmritiTab account. Browser data can still be subject to Chrome profile settings, browser sync and the permissions you grant.

Get started

Up and running
in a few steps.

SmritiTab is currently being prepared for release. The repository is the source of truth for builds and release availability.

STEP 01

Get the latest build

Check the GitHub Releases page for a published, packaged extension build.

STEP 02

Open Chrome extensions

Visit chrome://extensions. For a developer build, enable Developer mode.

STEP 03

Load and open a new tab

Choose Load unpacked and select the extracted extension folder, then open a new tab.

Developer installation is intended for testing. A Chrome Web Store listing will be linked here if and when one is published.

Good to know

Frequently asked
questions.

Is SmritiTab free?

SmritiTab is an open-source project repository. Check its releases and repository for the current distribution and licensing details. No paid plan is advertised here.

Does it work without an internet connection?

Core dashboard tools and bundled wallpapers are local. Search and weather need a connection, and optional remote wallpapers need internet access when selected.

Does SmritiTab upload my notes or bookmarks?

The current implementation stores dashboard data locally in the browser and has no SmritiTab backend or telemetry. Your use of external browser services and Chrome profile sync remains governed by those providers.

Which browser is supported?

SmritiTab is built as a Chrome Manifest V3 extension. Other Chromium browsers may behave differently and are not claimed as officially tested here.

Where can I report a bug or request a feature?

Open an issue in the GitHub repository with steps to reproduce and relevant browser details.
